# 音檔來源與授權

本資料夾的音檔都是教育部公開授權的素材，**原檔照原樣存放、沒有剪輯或轉檔**。網頁播放時只用 Web Audio 播原檔開頭字音那一段、並在播放時調整音量，不改動檔案本身。對照表在 `data/zhuyin-audio.js`。

## moe-dict/ — 國語辭典簡編本單字屬性聲音檔

- 中華民國教育部（Ministry of Education, R.O.C.）。《國語辭典簡編本》（版本編號：2014_20260929）網址：https://dict.concised.moe.edu.tw/
- 授權：創用 CC－姓名標示－禁止改作 臺灣 3.0 版（CC BY-ND 3.0 TW），https://creativecommons.org/licenses/by-nd/3.0/tw/legalcode
- 依授權要求，完整保留教育部的使用說明：`moe-dict/國語辭典簡編本公眾授權使用說明.pdf`
- 下載來源：https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/dict_concised_download.html 的「單字屬性聲音檔」（`dict_concised_music_word_2014_20260929.zip`），只取出題庫用到的字。
- 檔名是辭典的字詞號（例如 `4848.wav` = 船）。每個檔約 10 秒，開頭第一段是字音，後面是其它屬性說明。
